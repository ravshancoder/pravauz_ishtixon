# Prava UZ Ishtixon — o'quv markazi sayti

Statik sayt (HTML + CSS + JS), serversiz. GitHub Pages'da ishlaydi.

## GitHub Pages'ga joylash
1. GitHub'da yangi repository yarating (masalan `pravauz-ishtixon`).
2. `index.html`, `style.css`, `script.js` fayllarini yuklang.
3. **Settings → Pages → Branch: `main` / `(root)` → Save**.
4. 1–2 daqiqadan so'ng sayt `https://<username>.github.io/<repo>/` manzilida ochiladi.

## Ma'lumotlarni o'zgartirish
- Telegram admin: `script.js` boshidagi `CONFIG.telegram`.
- Statistika raqamlari: `index.html` ichida `data-count` qiymatlari.
- Kurslar, savollar, manzil: `index.html`.
- Ariza formasi Telegram (`@Farxod2626`) ichida tayyor xabar bilan ochiladi.
